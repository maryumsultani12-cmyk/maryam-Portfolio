BookHub — Online Book Platform.

A user-friendly platform for exploring and reading books, with categorized content and a clean reading experience.

HTMLCSSBootstrapJavaScriptPHPMySQL
Overview

Why it exists.

Readers browsing by category, not scrolling one long list.

BookHub is an online reading platform built for people who want to browse books by category and get straight to reading, without a cluttered interface getting in the way.

The focus was on a clean, distraction-free reading experience: organized categories, clear book listings, and simple navigation between browsing and reading.

Category-based browsing
Book listing pages

MySQL-backed book catalog
Build

How it was built.

A catalog structure with a simple, focused frontend.



View on GitHub →

Frontend. HTML, CSS and Bootstrap shape a responsive layout that adapts to any screen size, while JavaScript powers category filtering and smooth in-page navigation.

Backend. PHP pulls book and category data from a MySQL database, so adding or updating titles doesn't require touching the frontend at all.

Design decisions. Categories were kept front and center so readers can narrow down what they want in one or two clicks, rather than searching through everything.

Outcome. A lightweight, easy-to-navigate reading platform that stays fast even as the book catalog grows.
